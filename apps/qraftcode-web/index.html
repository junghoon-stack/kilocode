✳QraftCode 서비스 이용 안내

QraftCode는 누구나 다양한 AI 모델을 이용할 수 있도록 각 AI API 제공사의 무료 사용량(Free Tier)을 활용하는 것을 목표로 합니다. 무료 티어 특성상 사용량 제한, 일시 중단, 응답 지연, Provider 정책 변경 또는 모델 이용 불가가 발생할 수 있습니다. AI는 모두를 위한 것이어야 합니다.

A Note About QraftCode Availability
QraftCode aims to use free-tier allocations to make AI accessible. Limits, interruptions, delays, provider policy changes, and temporary model unavailability may occur. AI should be accessible to everyone.
